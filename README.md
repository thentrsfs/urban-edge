# URBANEDGE

A modern fashion ecommerce experience built with Next.js, TypeScript, Tailwind CSS, GSAP, Zustand, and Stripe.

## Overview

URBANEDGE is a cinematic streetwear-inspired ecommerce application focused on immersive UI, smooth interactions, and modern frontend architecture.

The project features dynamic product pages, animated transitions, responsive layouts, cart state management, and Stripe checkout integration in test mode.

## Features

- Modern ecommerce UI
- Dynamic product pages
- Responsive design
- Shopping cart with Zustand
- Stripe Checkout integration
- Animated interactions with GSAP
- Mobile navigation system
- Product recommendations
- Toast notifications
- Optimized image handling with Next.js Image
- App Router architecture

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Zustand
- GSAP
- Stripe
- Sonner
- Vercel

## Installation

Clone the repository:

```bash
git clone https://github.com/thentrsfs/urbanedge.git

npm install

npm run dev

```

### Environment Variables

Create a .env.local file and add:

STRIPE_SECRET_KEY=your_secret_key
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=your_publishable_key
NEXT_PUBLIC_BASE_URL=http://localhost:3000


### Stripe Test Mode

This project uses Stripe test mode.

Use the following test card: 4242 4242 4242 4242

Any future expiration date and any CVC will work.
